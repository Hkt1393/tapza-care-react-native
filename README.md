## Android Build

The installable Android build for Tapza Care is available through Expo EAS.

**Build link:** https://expo.dev/accounts/hk1309/projects/RnBaseProject/builds/c4358050-8158-40bf-b022-d2464af9ad7f

### Installation
1. Open the Expo build link.
2. Download the APK using the available download option.
3. Transfer the APK to an Android device if needed.
4. Open the APK and allow installation from that source if Android prompts you.
5. Install and launch Tapza Care.
